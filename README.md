🚀 Uruchomienie projektu

Upewnij się, że masz zainstalowanego Pythona (>= 3.14).

Sklonuj repozytorium lub pobierz pliki projektu.

Uruchom program poleceniem:

python main.py

🎮 Obsługa programu

Po uruchomieniu aplikacji dostępne jest menu:

Dodawanie pozycji (Książka / Film / Gra)

Usuwanie pozycji

Wyszukiwanie po tytule

Edycja danych

Dodawanie ocen (0–10)

Wyświetlanie wszystkich zapisanych pozycji

Automatyczne zapisywanie danych do pliku JSON przy zamknięciu programu

💾 System zapisu danych

Program wykorzystuje plik:

dane.json – do przechowywania bazy mediów

Jeżeli plik nie istnieje, zostanie utworzony automatycznie podczas pierwszego zapisu.

🏗️ Technologie

Python

JSON jako lokalna baza danych

⚠️ Uwagi

Tytuły są porównywane bez uwzględniania wielkości liter.

Oceny muszą mieścić się w zakresie 0–10.

Dane są zapisywane automatycznie przy:

Dodawaniu pozycji

Usuwaniu pozycji

Edycji danych

Zamykaniu programu
